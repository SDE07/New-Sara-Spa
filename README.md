# New Sara SPA – Table & Management System

A modern, fast, and responsive Single Page Application (SPA) designed with structured data tables, clean folder organization mirroring Currymiya, and fully powered by Tailwind CSS.

## 🚀 Features
- **Folder Structure**: Mirroring Currymiya architecture (`src/common`, `src/components`, `src/data`, `src/hooks`).
- **Clean Table UI**: Search, pagination, filter, and action-ready tabular design.
- **Tailwind CSS**: Integrated with Vite and `@tailwindcss/vite`.
- **Dynamic SEO**: Meta and title injection via `useSEO` hook.
- **React Router**: Full SPA routing and lazy-loaded views.

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
